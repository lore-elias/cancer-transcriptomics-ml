# Cancer Transcriptomics: Machine Learning

## Project Overview

This project explores the application of machine learning to cancer transcriptomics data.

The goal is to investigate whether gene expression profiles can be used to distinguish between biological sample groups and identify genes that may contribute to these differences.

## Objectives

- Obtain and explore a public gene expression dataset.
- Perform data cleaning and preprocessing.
- Conduct exploratory data analysis.
- Build and evaluate machine learning classification models.
- Identify biologically relevant patterns in gene expression.
- Document the analysis in a reproducible workflow.
